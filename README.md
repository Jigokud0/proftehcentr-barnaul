# Профтехцентр — Барнаул

Адаптивный сайт сервиса по ремонту бытовой и климатической техники. React + Vite. Готов к импорту публичного GitHub-репозитория в Lork.

## Запуск и сборка

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Сборка запускает TypeScript, затем Vite. Корневой `tsconfig.json` включён специально для публикации в Lork. JavaScript/JSX-проект, точка входа `src/main.jsx`, корневой `index.html`. Серверные функции, переменные окружения и собственная база данных не нужны.

## Что внутри

- Шесть основных направлений ремонта.
- Прозрачные условия и отдельная таблица стоимости диагностики при отказе от ремонта.
- Настоящие фотографии из карточки сервиса, просмотр увеличенного фото.
- Конструктор обращения: выбор техники, марка/модель, описание проблемы; копирование сообщения и отдельный переход в MAX.
- Звонки, контакты и Яндекс Карты, мобильное меню, FAQ.
- Фотографии лежат локально. Manrope загружается через Google Fonts, запасной шрифт — Arial.

Форма ничего не отправляет на сервер и не показывает фиктивного успеха отправки заявки. Пользователь сам копирует описание и отправляет его в MAX. Копирование работает в защищённом контексте HTTPS или localhost.

Барнаул, Попова, 77А. Ежедневно 09:00–21:00. Телефон +7 (960) 964-57-00. Профиль MAX взят из карточки.

Прайс из карточки: диагностика стиральных машин, духовых шкафов, варочных панелей и водонагревателей при отказе от ремонта — 750 ₽; холодильников и кондиционеров — 1000 ₽. При продолжении работ выезд и диагностика бесплатны. Это не цена самого ремонта. Стоимость ремонта согласовывается с заказчиком до начала работ. Гарантия на запчасти и работы — до года; конкретные условия необходимо уточнять. Эти сведения сохранены в первоначальном контексте исходных материалов вне публичного репозитория.

Фотографии показывают реальные материалы сервиса; подписи не приписывают им неподтверждённые результаты, сроки или стоимость. Примеры симптомов — подсказки для обращения, а не дистанционная диагностика. Отзывы, стаж, количество заказов и партнёрские статусы не выдумывались.
